# 失眠剧本社

在 SillyTavern 里玩剧本杀的酒馆助手脚本：AI 当 DM、NPC 演员和其他玩家，你带着自己的角色卡入座。现在是 v0.x 测试版。

## 安装

需要先装好 [酒馆助手（JS-Slash-Runner）](https://n0vi028.github.io/JS-Slash-Runner-Doc/)，不需要别的预设、正则或扩展。

1. 酒馆 → 扩展 → 酒馆助手 → 脚本库 → 全局脚本 → 新建脚本。
2. 名字随便填（比如"失眠剧本社"），内容只写下面这一行，保存并启用：

   ```js
   import 'https://testingcf.jsdelivr.net/gh/zin1111917-blip/test@main/dist/insomnia/index.js';
   ```

3. 刷新酒馆。输入框附近会出现提灯，或者在酒馆助手按钮条里点"剧本杀"打开面板。

电脑和手机用同一行就行；以后更新，刷新酒馆就是新版（jsDelivr 有缓存，偶尔要等一会儿）。

## 你的数据在哪

- 导入的剧本、店员名册、图片、字体：存在你这个浏览器本地（换设备要用面板里的"导出 / 导入"搬过去）。
- API 预设和密钥、面板设置、存档、往期记录：存在你自己的酒馆里。导出备份时密钥会被去掉。
- 插件第一次开局时会自己建一本"失眠剧本社"世界书并挂到全局；没开局时里面的条目都是关着的。

本仓库只有打包好的插件代码，不包含任何人的剧本、聊天或设置。
