# 失眠剧本社

在 SillyTavern 里玩剧本杀的酒馆助手脚本：AI 当 DM、NPC 演员和其他玩家，你带着自己的角色卡入座。现在是 v0.x 测试版。

## 安装

需要先装好 [酒馆助手（JS-Slash-Runner）](https://n0vi028.github.io/JS-Slash-Runner-Doc/)，不需要别的预设、正则或扩展。

1. 酒馆 → 扩展 → 酒馆助手 → 脚本库 → 全局脚本 → 新建脚本。
2. 名字随便填（比如"失眠剧本社"），内容只写下面这一行，保存并启用：

   ```js
   import 'https://testingcf.jsdelivr.net/gh/zin1111917-blip/test@main/dist/insomnia/loader.js';
   ```

3. 刷新酒馆。输入框附近会出现提灯，或者在酒馆助手按钮条里点"剧本杀"打开面板。

电脑和手机用同一行就行；以后更新，刷新酒馆就是新版（这一行加载的是一个小加载器，它每次去 GitHub 查最新版本再加载，不受 jsDelivr 缓存影响）。

以前写的是 `…/dist/insomnia/index.js` 的，改成上面这行。

## 怎么玩

第一次打开面板会有五张小卡片的引导（设置 → 面板 → 新手引导 可以重看）。简单说：

1. **准备**：插件自己的请求（排人、写本、导入解析）默认用酒馆当前的连接；想分开用别的模型，在菜单 → API 设置里配。
2. **找本**：菜单 → 书架。可以导入你手里的剧本（文字、Word、PDF、图片都行，导入时会先估算要发几次请求），也可以让 AI 写一本。想先试试，用教程本《雨夜旧书店》。
3. **开局**：点封面 → 开局，按向导选人入座（你的角色卡、常客、AI 补位）、选带本的 DM。插件会在这个聊天里记进度。
4. **玩**：正文照常在酒馆里聊。面板里随时翻本子、看线索、记笔记、画关系和时间线；页头"给 DM"可以预约下一步。重 roll、删消息，进度跟着退回。
5. **音乐**（可选）：设置 → 音乐。剧本里到点要放歌时提示该放哪首，或者在剧本详情 → 曲库里传音频后自动放。
6. **散场**：菜单里散场，插件把这局临时改过的世界书条目恢复原样，并留一条往期记录。

## 你的数据在哪

全部在你自己的酒馆里，电脑和手机打开同一个酒馆就共用：
- 剧本、店员名册、图片、字体：每台设备的浏览器里存一份（快、断网也能玩），酒馆的用户文件目录里存一份共用的（文件名以 `insomnia_` 开头），打开酒馆、改动之后会自动同步。设置 → 存储空间能看到同步状态。
- API 预设和密钥、面板设置、改过的提示词、存档、往期记录：存在酒馆的设置里（全局变量「失眠剧本社」）。导出备份时密钥会被去掉。
- 两台设备同时开着时，设置是整份保存的，后保存的一方会盖掉另一方刚改的设置；换设备前刷新一下就好。
- 插件第一次开局时会自己建一本"失眠剧本社"世界书并挂到全局；没开局时里面的条目都是关着的。

本仓库只有打包好的插件代码，不包含任何人的剧本、聊天或设置。
